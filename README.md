# 🚀 HeroStack - Modern App Discovery Platform

**HeroStack** is a sleek and responsive application marketplace built with **React**, **React Router**, and **Tailwind CSS**. Designed with a focus on performance and clean UI, it allows users to discover, search, and manage app installations with ease.

---

## 🌟 Key Features

### 1. **Dynamic Market Exploration**

- **Live Search:** Find any application instantly with a real-time search engine.
- **Intelligent Sorting:** Organize apps by **Downloads** (High to Low & Low to High) to discover trending tools.
- **Search Loading States:** Visual feedback during search operations for a premium feel.

### 2. **Installation Management**

- **One-Click Install:** Quickly add apps to your personal collection.
- **Data Persistence:** Integrated with **LocalStorage** to ensure your installed apps remain saved even after a refresh.
- **My Installations Page:** A dedicated dashboard to view, sort, and uninstall your apps.
- **Interactive Feedback:** Real-time toast notifications for successful installations or uninstalls.

### 3. **Advanced Performance & UX**

- **Navigation Loaders:** Global loading indicators during page transitions for seamless navigation.
- **Figma-to-Code Accuracy:** Built with pixel-perfect attention to detail using modern Tailwind utility classes.
- **Fully Responsive:** Smooth experience across mobile, tablet, and desktop devices.

---

## 🛠️ Tech Stack

- **Core Framework:** React.js (Vite)
- **Styling:** Tailwind CSS
- **Icons:** Lucide-React
- **Routing:** React Router v7
- **Notifications:** React Hot Toast
- **Data Fetching:** Fetch API with async/await
